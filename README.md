# Payment Checkout Challenge

Aplicación full stack para gestionar el proceso de compra de un producto,
procesamiento de pago en ambiente Sandbox, información de entrega y
actualización de inventario.

## Tecnologías

### Frontend

- React
- TypeScript
- Vite
- Redux Toolkit
- Tailwind CSS
- React Hook Form
- Zod
- Jest
- React Testing Library

### Backend

- NestJS
- TypeScript
- Prisma ORM
- PostgreSQL
- Jest
- Swagger

### Infraestructura local

- Docker
- Docker Compose
